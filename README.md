# Raylib Bouncing Ball Simulation

A smooth 2D bouncing ball physics simulation with dynamic motion trails, glow shaders, and speed controls built in C using **raylib**.

## Controls
- **SPACE**: Pause / Resume
- **UP ARROW**: Increase ball velocity / boost
- **DOWN ARROW**: Decrease ball velocity
- **R**: Reset position
- **ESC**: Exit

## How to Run (Windows)
1. Open this repository folder in VS Code.
2. Open `bouncing_ball.c`.
3. Press `Ctrl + Shift + B` to compile and run.
